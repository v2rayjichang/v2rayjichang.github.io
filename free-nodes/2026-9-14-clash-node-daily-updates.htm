一、Quantumult简介与基本概念

什么是Quantumult？

Quantumult是一款面向iOS平台的网络代理软件，支持多协议代理服务，帮助用户突破网络限制，保护上网隐私。其强大的自定义参数设定和丰富的功能模块，使其不仅适合普通用户，也满足高级用户的个性化需求。

基础概念解析

  • 代理（Proxy）：通过代理服务器转发网络请求，隐藏用户真实IP地址，绕过网络限制。

  • 规则（Rules）：用于判断哪些网络流量走代理，哪些流量直连，提升访问效率。

  • 配置文件（Configuration File）：保存代理服务器、规则、脚本等全部设定，是Quantumult运行的核心。

理解这几个基础概念，有助于您更好地掌握Quantumult的配置技巧。

三、Quantumult的基本参数设定

1. 代理服务器添加与管理

Quantumult支持多种代理类型，包括HTTP、HTTPS、SOCKS5等，用户可以灵活添加：

  • 路径：进入“设置” → “代理” → “添加代理”。

  • 配置代理信息：填写代理服务器地址、端口号、用户名和密码（如需）。

  • 选择代理类型：根据代理服务选择对应协议。

添加完成后，代理列表会自动更新，方便管理和切换。

2. 规则的设置与优化

规则决定哪些流量通过代理，哪些流量直连：

  • 添加规则：在“设置” → “规则”中添加自定义规则。

  • 规则格式：支持域名匹配、IP段匹配等多种格式。

  • 优先级管理：规则顺序影响匹配效果，优先级高的规则优先应用。

合理配置规则，既能保障访问速度，又能确保关键流量通过代理。

3. 配置文件的导入

配置文件集中保存所有代理和规则信息，导入方式多样：

  • 本地导入：在“设置” → “配置文件” → “导入”中选择本地文件。

  • 在线导入：通过配置文件URL直接导入，方便快捷。

导入后，Quantumult自动应用配置，极大简化设置流程。

Quantumult支持多种脚本语言，用户可以通过脚本实现高级功能：

  • 添加脚本：进入“设置” → “脚本”，导入或编写自定义脚本。

  • 常用脚本应用：实现广告屏蔽、智能分流、自动切换节点等。

  • 语言支持：JavaScript等主流脚本语言，扩展功能强大。

脚本极大提升了Quantumult的灵活性和自动化水平。

2. 订阅功能

订阅功能方便用户批量管理代理服务器：

订阅使节点管理更便捷，维护代理稳定性更简单。

FAQ

VLESS + XTLS 模式在高并发下有什么优势？
XTLS 模式减少握手次数和加密冗余，提高 CPU 利用率和吞吐量。在高并发场景下能保持连接稳定，适合游戏、流媒体和频繁请求的网络环境，提升整体性能。
Sing-box 如何实现域名精确分流？
Sing-box 支持按域名匹配流量，将不同应用流量分配到指定节点。结合策略组使用，可自动选择最优节点，提高访问速度和网络稳定性，实现精确流量管理。
PassWall2 如何通过策略组提升科学上网体验？
PassWall2 结合策略组和延迟检测功能，可自动选择最优节点处理网页、视频和游戏流量。无需手动切换，保证访问速度、稳定性和整体网络体验。
Hysteria2 的 QUIC 传输在高丢包环境下表现如何？
QUIC 基于 UDP，具备拥塞控制和重传机制，在高丢包环境下仍能保持稳定连接。Hysteria2 利用 QUIC 特性，使流量高效传输，延迟低且稳定性好。
如何检查 Clash 连接失败的日志以定位问题？
打开 Clash 的日志面板或查看配置目录下的 log 文件，观察报错信息如 DNS 解析失败、节点拒绝连接或 TLS 握手错误。根据关键字（例如 timeout、refused、certificate）逐项排查并比对服务器配置。
Surfboard 如何实现按应用分流？
Surfboard 支持通过策略组和规则文件按应用分流，将不同应用的流量分配到不同节点。这样可保证游戏或视频走低延迟节点，提高访问速度并优化网络体验。
Surfboard 可以导入哪些格式的规则文件？
Surfboard 支持 YAML 和部分 JSON 格式的规则文件，用户可以导入节点、策略组和分流规则。注意文件格式和语法必须符合 Surfboard 规范，否则可能导入失败。
Netch 全局代理与规则代理的区别是什么？
全局代理会将所有流量通过节点转发，适合游戏或全局科学上网；规则代理只针对指定应用或 IP 走节点，优化带宽利用和网络效率，根据不同需求选择使用模式。
Potatso Lite 是否可以导入多个节点？
支持。用户可手动输入或扫描二维码导入多个节点，并可修改或删除节点信息。虽然不支持自动订阅更新，但足以满足轻量用户对节点管理和分流需求。
Mihomo 的节点管理支持批量操作吗？
Mihomo 支持批量导入、删除和更新节点。通过策略组和分类管理，用户可以高效地管理数百个节点，同时进行测速和节点切换，提高操作效率。
