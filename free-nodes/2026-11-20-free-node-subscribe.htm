一、什么是Quantumult？——不仅是一个代理工具

Quantumult 是一款为 iOS 平台量身打造的网络代理工具，由中国开发者推出，尽管界面看起来极简，但背后功能却极为强大。

它不仅支持包括 HTTP、HTTPS、SOCKS5、VMess、Trojan、Shadowsocks 等在内的多种代理协议，还内置了 图形化规则编辑器、分流系统、网络监控与重定向功能。它可以让你精确控制每一个网络请求的走向，并对节点连接状况一目了然。

核心优势总结：

  • 支持协议广泛：主流协议几乎全覆盖；

  • 高可定制性：分流规则、策略组灵活自由；

  • 数据可视化：实时查看流量与请求路径；

  • 轻巧高效：在iOS平台上几乎无资源压力。

1. 从App Store获取应用

  • 打开 App Store；

  • 搜索 Quantumult；

三、获取可用服务器节点信息

在使用Quantumult连接网络之前，用户必须获取一个合法、可用且与协议匹配的代理服务器信息。

常见获取方式：

  • 购买代理服务：选择信誉良好的服务商（如V2ray、Trojan、Shadowsocks提供商）；

  • 订阅链接：通过提供商获取订阅URL，一键导入；

  • 扫描二维码：服务商通常提供配置二维码，便于扫码添加；

  • 自建服务端：高阶用户可部署自有服务器（例如搭建VMess或Trojan节点）。

一个典型的VMess配置内容包含：

  • 地址（IP或域名）

  • 端口号

  • UUID（用户识别码）

  • 加密方式

  • TLS状态（是否启用）

  • 传输协议（如TCP/ws）

  • 路径与主机名（ws使用时必填）

四、在Quantumult中添加服务器节点的详细步骤

一旦你获得了服务器信息，接下来就是将这些信息导入Quantumult。我们分别介绍手动添加与订阅导入两种方式。

✅ 方法一：订阅链接导入（推荐方式）

  1. 打开Quantumult；

  2. 点击右下角“设置”图标，选择【配置文件】；

  3. 点击右上角“+”图标；

  4. 选择“订阅”；

  5. 粘贴订阅链接，点击“完成”；

  6. 返回主界面，手动点击“更新”图标，拉取最新节点。

这样，一批节点会自动导入Quantumult，方便你一键切换、自动测速、策略分组。

✅ 方法二：手动添加服务器

如果你只有单独的节点信息或二维码：

  1. 打开Quantumult主界面；

  2. 点击右上角“+”图标，选择“手动添加”；

  3. 根据服务器提供的协议类型选择：VMess、Trojan、Shadowsocks等；

  4. 按要求填写地址、端口、UUID、加密方式、TLS状态等信息；

  5. 为节点命名，如“东京CN2高速”或“美西GIA专线”；

  6. 点击保存，节点即添加完成。

如果是二维码，则可在“设置” → “配置”页面点击二维码图标进行扫码添加。

五、配置策略组与分流规则

Quantumult最强大之处在于它的规则机制，可以决定哪些流量需要走代理、哪些直连、哪些拦截。

1. 创建策略组

策略组可以将多个节点集合在一起，根据不同用途进行分配，例如：

  • 【全球加速】：访问海外站点

  • 【国内直连】：保留访问国内App（如微信、淘宝）

  • 【广告拦截】：自动阻断追踪链接

进入“设置” → “策略组”可添加或编辑这些组。

2. 添加分流规则

  • 点击“设置” → “规则”；

  • 你可以选择导入通用规则（如GFWList、ChinaList）；

  • 或者手动新增：

    • DOMAIN-SUFFIX,google.com,全球加速

    • DOMAIN-SUFFIX,baidu.com,国内直连

    • IP-CIDR,127.0.0.0/8,DIRECT

支持的匹配方式包括：域名后缀、IP段、端口范围、关键字等。

六、连接服务器与状态检测

  1. 返回Quantumult主界面；

  2. 选择你想启用的服务器节点；

  3. 点击右上角“开关”图标，启用VPN代理；

  4. 状态栏出现VPN图标，表示连接成功；

  5. 此时访问被屏蔽的网站或App（如Telegram、Google）应能正常加载。

Quantumult还支持 延迟测速，在“服务器列表”长按节点选择“Ping测试”，可测出响应时间。

七、实用技巧与优化建议

✅ 自动测速并切换节点

  • 设置策略组类型为“延迟最低自动选择”；

  • Quantumult将自动在多个节点中选择延迟最低的那个；

  • 特别适合网络不稳定时提升连接体验。

✅ 设置DNS防污染

  • 在“设置” → “DNS”中自定义DNS服务器：

    • 推荐：1.1.1.1, 8.8.8.8, 223.5.5.5

  • 开启“DoH/DoT”选项提高解析安全性；

  • 可启用“Fake IP”加快解析速度，减少DNS污染。

✅ 自动更新订阅配置

  • 在订阅链接下拉时自动刷新；

  • 可开启定时自动刷新功能，确保节点信息始终有效。

八、常见问题解答（FAQ）

Q1：Quantumult无法连接服务器怎么办？

排查方式如下：

  • 检查节点地址、端口、UUID等是否填写正确；

  • 检查网络状态（建议切换蜂窝/Wi-Fi尝试）；

  • 更换节点看是否是服务器问题；

  • 确保Quantumult已获得VPN权限。

Q2：如何导入多个订阅？

进入“设置” → “配置文件” → “+”，可以添加多个订阅链接，系统将自动合并节点信息，并归类至不同策略组。

Q3：Quantumult支持哪些协议？

支持范围极广，包括但不限于：

  • Shadowsocks

  • VMess（v2ray）

  • Trojan

  • SOCKS5

  • HTTP/HTTPS

同时也支持自定义混合使用不同协议节点，非常灵活。

Q4：如何拦截广告？

Quantumult可通过规则拦截广告：

  • 导入广告拦截规则（如AdGuard、EasyList CN）；

  • 使用策略组设置为“拒绝连接”；

  • 配合Safari内容拦截器，双重屏蔽效果更佳。

FAQ

Hiddify Next 如何管理用户流量配额？
管理员可以为每个用户设置上传和下载带宽以及总流量上限。超出限制可自动降速或阻止访问，保证服务器资源合理分配，提高整体网络公平性和用户体验。
SSR 节点和 V2Ray 节点可以混合使用吗？
可以，但要使用支持多协议的客户端，如 Clash、Sing-box、Mihomo 等。这类客户端能在同一配置文件中加载不同协议的节点，通过规则分流让 SSR 与 V2Ray 同时工作。
VLESS 的 XTLS 模式如何提升性能？
VLESS + XTLS 模式可以在加密传输中减少 TLS 握手和数据复制过程，从而显著降低延迟并减少 CPU 占用。这种优化特别适合高带宽或高并发的场景。
Shadowrocket 节点测速功能如何优化连接？
Shadowrocket 定期测速节点延迟和丢包率，并结合策略组自动切换到最佳节点。保证网页、视频和游戏流量通过最优路径，提高访问速度和连接稳定性。
V2Ray QUIC 模式适合高丢包网络吗？
QUIC 基于 UDP 协议，支持多路复用和零握手，能在高丢包和不稳定网络中减少延迟和丢包。适合视频、游戏和即时通讯等高频应用场景，提高稳定性和速度。
WinXray 的测速功能不显示结果怎么办？
测速依赖于节点响应时间与服务器网络质量。若测速为空白，请检查系统时间同步、网络防火墙及代理端口设置是否正确；也可更新到最新版本修复已知测速模块异常问题。
Quantumult X 可以用脚本自动切换节点吗？
可以。Quantumult X 支持通过脚本逻辑判断网络延迟或连接失败情况，并自动切换节点。用户可以编写自定义 JS 规则，从而实现智能代理与按需分流，适合高级用户使用。
如何在手机上减少代理应用对电量的消耗？
关闭不必要的后台代理连接，减少实时测速或心跳频率，启用省电模式并限制流量统计与日志记录；对于常用站点设置直连策略，避免所有流量都走代理带来的持续网络负荷。
Mihomo 是什么项目？
Mihomo 是 Clash Meta 的继任版本，也被称为 Clash.Meta 的社区分支。它优化了性能，支持更多协议如 Hysteria2、TUIC 等，同时提供更灵活的规则匹配系统，是目前非常流行的分流代理核心。
Nekoray 的内置延迟测试为什么与系统 ping 不同？
客户端的延迟测试通常基于 TCP 或特定探测包，而系统 ping 使用 ICMP，两者网络路径与优先级可能不同。此外，防火墙或服务器对 ICMP 的响应可能被限制，导致测试结果存在差异。
